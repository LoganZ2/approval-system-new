# 审批系统前端项目

## 项目结构

```
frontend/
├── miniprogram/           # 微信小程序项目
│   ├── app.js            # 小程序入口文件
│   ├── app.json          # 小程序配置文件
│   ├── app.wxss          # 小程序全局样式
│   ├── project.config.json # 小程序项目配置
│   ├── sitemap.json      # 小程序搜索配置
│   ├── pages/            # 页面目录
│   │   ├── index/        # 首页
│   │   ├── approval/     # 审批页面
│   │   └── profile/      # 个人中心
│   └── images/           # 图片资源
└── README.md             # 项目说明
```

## 技术栈

- **微信小程序原生框架** - 使用微信官方小程序开发框架
- **WXML** - 小程序模板语言
- **WXSS** - 小程序样式语言
- **JavaScript** - 小程序逻辑层

## 功能特性

### 已实现功能

1. **首页**
   - 欢迎页面
   - 用户信息展示
   - 快速导航

2. **审批页面**
   - 审批列表展示
   - 审批状态管理（待审批/已通过/已拒绝）
   - 新建审批功能

3. **个人中心**
   - 用户信息展示
   - 功能菜单导航
   - 退出登录

### 待实现功能

- 审批详情页面
- 新建审批表单
- 我的申请列表
- 待我审批列表
- 设置页面
- 与后端API集成

## 开发说明

### 环境要求

- 微信开发者工具
- Node.js (可选，用于构建工具)

### 开发步骤

1. 使用微信开发者工具打开 `frontend/miniprogram` 目录
2. 在开发者工具中预览和调试
3. 修改代码后实时预览效果

### 图片资源

需要在 `images` 目录下添加以下图片文件：

- 首页图标 (home.png, home-active.png)
- 审批图标 (approval.png, approval-active.png)  
- 个人中心图标 (profile.png, profile-active.png)
- 默认头像 (default-avatar.png)

## 部署说明

1. 在微信开发者工具中点击"上传"
2. 在微信公众平台提交审核
3. 审核通过后发布

## 注意事项

- 小程序需要使用真实的AppID才能正常使用部分功能
- 图片资源需要自行添加或替换
- 需要配置后端API接口地址
